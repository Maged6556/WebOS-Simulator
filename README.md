# WebOS-Simulator
This project was created as a university Operating Systems project to demonstrate both **frontend development skills** and core **OS concepts** in an interactive browser experience.

## Features

### Authentication System

* Modern glassmorphism login screen
* Username / password validation
* Logout system
* Session storage support

### Desktop Environment

* Linux-inspired desktop layout
* Interactive desktop icons
* Responsive taskbar with live clock/date

### Window Management

* Draggable windows
* Minimize / close controls
* Active window focus system
* Smooth animations and transitions

### Applications

* **File Manager**

  * Folder navigation
  * Create / rename / delete items

* **Terminal Emulator**

  * Linux-style command interface
  * Simulated commands such as:

    * ls
    * pwd
    * mkdir
    * touch
    * clear
    * whoami
    * uname

* **Text Editor**

  * Write notes
  * Save data using LocalStorage

### Operating System Concepts

#### Process Management

* Every opened app runs as a simulated process
* PID generation
* Process states:

  * Running
  * Waiting
  * Terminated

#### Memory Management

* Simulated RAM usage per application
* Dynamic memory release when apps close

#### I/O Management

* Keyboard input
* Mouse interactions
* Terminal output
* Real-time UI updates

### UI / UX

* Glassmorphism design
* Smooth transitions
* Clean modern interface
* Fully responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* LocalStorage API

## Purpose

This project combines user interface engineering with Operating Systems fundamentals to create a lightweight Linux-like desktop experience directly in the browser.
