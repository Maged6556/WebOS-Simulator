# WebOS Simulator 🚀

A modern, interactive Web-based Operating System simulator built as a university project to demonstrate **Operating Systems fundamentals** through a premium **Frontend experience**.

---

## ✨ Key Features

### 🖥️ Desktop & UI/UX
- **Premium Glassmorphism**: High-end visual design with blur effects and transparency.
- **Inter Font**: Modern, clean typography for a professional look.
- **Interactive Icons**: Draggable desktop icons for both system apps and user files.
- **Context Menu**: Right-click on the desktop to create files/folders or delete existing ones.
- **Taskbar**: Fully functional taskbar with a live clock, calendar, and active process tracking.

### 🪟 Window Management
- **Draggable & Resizable**: Full control over window positioning and dimensions.
- **Window Controls**: Minimize, Maximize/Restore, and Close functionality.
- **Active Focus**: Intelligent z-index management to focus on the active application.

### 📁 Virtual File System (VFS)
- **Persistence**: Your files and folders are saved locally using the `LocalStorage API`.
- **Desktop Integration**: Files created on the desktop stay there, even after a refresh.
- **VFS Operations**: Support for nested directories and file content management.

### 🛠️ Core Applications
- **📂 File Manager**: Navigate through the system, manage files, and organize folders.
- **💻 Terminal**: A powerful Linux-style CLI supporting commands like `ls`, `cd`, `mkdir`, `cp`, `mv`, `rm`, `cat`, `stat`, and more.
- **📝 Text Editor**: A simple editor to create and save notes directly to the VFS.
- **📊 System Monitor**: Real-time tracking of simulated PIDs, RAM usage, and process states.

---

## 🧠 OS Concepts Demonstrated

- **Process Management**: Simulated process lifecycle (Running, Waiting, Terminated) with unique PIDs.
- **Memory Management**: Dynamic RAM allocation and release per application.
- **I/O Management**: Handling keyboard shortcuts, mouse events, and terminal buffering.
- **User Authentication**: Secure-styled login system with session persistence.

---

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+).
- **Icons**: Font Awesome 6.
- **Typography**: Inter (Google Fonts).
- **Storage**: LocalStorage for persistent VFS and user settings.
